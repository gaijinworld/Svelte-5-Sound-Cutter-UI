# Changelog

All notable changes to SoundCutter are documented here.

## [0.1.0] - 2026-03-29
- Added the public open-source release baseline for SoundCutter.
- Shipped microphone recording, per-region presets, and the Tone.js effects workflow.
- Fixed all Svelte and TypeScript diagnostics so `pnpm check` passes cleanly.
- Simplified the repo by removing stale legacy audio-engine code and local tooling artifacts.
- Split project licensing from third-party notices and added CI, tests, and contributor setup docs.
